# **App Name**: SoulSync

## Core Features:

- User Authentication: Secure email/password sign-up and login using Firebase Authentication.
- User Pairing: Generate and use a unique 6-digit 'Pair Code' to link user profiles, stored in Firestore.
- Compatibility Quiz: Administer a 30-question quiz covering personality, attachment style, values, and love style.
- Data Storage: Store user responses and pair IDs in Firestore's 'responses' collection.
- Compatibility Engine: Compute a weighted compatibility score based on quiz answers.
- Results Dashboard: Display overall compatibility, strengths, and growth areas in a user-friendly report.
- Copy Pair Code: Tool to help users copy and paste Pair Codes, in order to more reliably share and sync

## Style Guidelines:

- Primary color: Soft blue (#A0D2EB) for a calming and trustworthy feel.
- Background color: Very light blue (#F0F8FF), almost white, for a clean and spacious interface.
- Accent color: Muted violet (#B19CD9) to highlight important elements and CTAs.
- Body and headline font: 'PT Sans' for a modern but still warm feel.
- Use minimalistic line icons to represent different compatibility aspects.
- Mobile-responsive design with clear sections for each quiz and result component.
- Subtle transitions and progress animations during quiz completion.
